# Spots

I am building the "Spots" social media web applications.

The profile user's Avatar image can now be changed/updated by clicking on it and pasting the image URL.
The profile user's Profile name (2-40 characters) and Profile description (2-200 characters) can also updated by clicking on the EDIT PROFILE button and saving the changes.

The user can also add new cards (posts) by pasting a URL of that image and adding some caption text. When submitted the new card is added to the top of the cards list. The image of that posted card can be clicked on and a larger view of the image will be shown along with it's caption.

The user can even like ❤️ existing cards.

When editting the existing profile info, adding a new card (post) or viewing an existing card in full view, the modal can now be closed using the escape key, clicking on the X or clicking outside of the window.

If the user tries to delete an existing card, a confirmation window will pop up. If DELETE is clicked that card will not exist even if the page is reloaded. If CANCEL is click the pop up will close and nothing will be changed.
